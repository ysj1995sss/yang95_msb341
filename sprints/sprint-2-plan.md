# Sprint 2 Plan

**Goal:** Users can search jobs by industry and role with flexible filtering — they can pick multiple options, one option, or no filters at all, and get real-time updates from different job websites.

**Why this:** It's the foundation of the product.

**Done looks like:** All steps 3–9 are working end-to-end: Set Job Search Goals, Select Job Sources, Scout Open Jobs, Clean & Validate Results, Job Discovery Dashboard, Calculate Candidate Fit, User Triage.

**Predicted difficulty:** 4

---

**Actual difficulty:** 4.

**Why it differed:** Most of the sprint went to resume tailoring quality, bug fixing and getting the product online, which the plan did not name as the goal.

**Retro:** No, I did not hit the goal. The product still has bugs, so the job-search flow cannot yet be called done end-to-end. Sprint 3 should start with those bugs and a live check of the search flow, before adding new features.
